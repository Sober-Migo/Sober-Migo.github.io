# Ahmed Magdy Hassan — Resume

Original XeLaTeX resume. GitHub is the source of truth for all claims.

## Compile (VS Code + MiKTeX + LaTeX Workshop)

1. Install **IBM Plex Sans** (and optionally IBM Plex Mono) on Windows.
2. Open the `resume` folder in VS Code.
3. Open `resume.tex`.
4. Set the recipe to **xelatex** (see instructions below).
5. Build with `Ctrl+Alt+B` or the green play button.

Fallback if fonts fail: compile `resume_pdflatex.tex` with pdflatex.
